Use the ScopeDB reference when you need the exact syntax, request shape, data type behavior, or function semantics for a feature.

If you want a guided path, start with [Connect to ScopeDB](/guides/connect-to-scopedb) or the [Quickstart](/guides/quickstart). If you already know what you need to check, use the sections below.

### [How to use this reference](/reference/how-to-use-this-reference)

Read the syntax notation, example conventions, and boundary between guides, concepts, and reference pages.

### [ScopeQL reference](/reference/commands)

Look up ScopeQL query clauses, operators, and statements such as `CREATE TABLE`, `INSERT`, and `CREATE INDEX`.

### [Data model reference](/reference/data-model)

Check how tables, typed columns, `object`, `any`, nested values, and missing values behave in ScopeDB.

### [Data type reference](/reference/data-types)

Look up ScopeDB data types, date/time behavior, semi-structured values, and conversion rules.

### [Function reference](/reference/functions)

Look up ScopeDB functions by category, including aggregate, string, date/time, conversion, semi-structured, search, window, and system functions.

### Performance and indexing

Index guidance belongs with performance optimization material. For exact `CREATE INDEX` syntax, see [CREATE INDEX](/reference/commands/statements/create-index).

### API and format reference

The HTTP API and wire-format reference is still being separated from the Developer guides. For now, see [HTTP API](/developer/http-api) for endpoint usage and examples.
